# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| >= 0.1  | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.

### Private Vulnerability Reporting

Use [GitHub Private Vulnerability Reporting](https://github.com/epicsagas/tdl/security/advisories) to disclose vulnerabilities responsibly.

- **Acknowledgement SLA**: 48 hours
- **Patch target SLA**: 90 days
- **Public disclosure**: After patch is released

### What to Include

- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fix (if known)

## Security Best Practices

- Never share your Tidal session tokens
- Use `--pkce` login for HiRes Lossless (more secure)
- Keep your Tidal credentials private
- Report security issues privately
